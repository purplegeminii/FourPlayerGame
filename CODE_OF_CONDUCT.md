Code of Conduct
===============

This project follows a simple, community-first Code of Conduct to make contributions welcoming and collaborative.

Expected behavior
-----------------
- Be respectful and considerate in language and actions.
- Give constructive, kindness-first feedback on issues and pull requests.
- Help new contributors get up to speed; share knowledge and pointers.

Unacceptable behavior
---------------------
- Harassment, hateful language, personal attacks, or abusive conduct.
- Disrespectful or exclusionary comments about protected classes or identities.
- Deliberate disruption of discussions or attempts to intimidate contributors.

Reporting
---------
If you experience or witness unacceptable behavior, please open an issue titled "Code of Conduct: report" (if safe to do so) or contact the project owner directly via the repository contact information. Include relevant details (what happened, when, and any participants).

Enforcement
-----------
Project maintainers will review reports in a timely manner. Reasonable, contextual actions may include asking for clarification, moderating comments, temporarily blocking accounts, or removing problematic content. In severe or repeated cases, contributors may be banned from the project.

Scope
-----
This Code of Conduct applies to all project spaces (issues, pull requests, commit comments, and community discussions) and events organized by the project.

Acknowledgements
----------------
This document is a short, plain-language code of conduct inspired by common community guidelines. For stricter or organization-level policies, consider adopting the full Contributor Covenant.
