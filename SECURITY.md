Security Policy
===============

We appreciate reports of security vulnerabilities. This document explains how to report security issues and what to expect from the maintainer.

Reporting a vulnerability (preferred)
-----------------------------------
1. Use GitHub's Security Advisories (recommended):
   - On GitHub, go to this repository, click "Security" → "Advisories" → "Create new draft advisory". This allows confidential communication with repository owners and maintainers.

Private reporting by email
--------------------------
If you cannot use GitHub Security Advisories or you prefer email, please send details to: <delalinsiah.asare@gmail.com>

If you prefer, you may open a private issue or use a contact method listed in the repository profile.

What to include in your report
------------------------------
- A short summary of the issue and the affected component(s).
- Steps to reproduce (minimal repro if possible) and expected vs actual behavior.
- Affected versions (if applicable).
- Any PoC (proof-of-concept) code, logs, or crash output.
- Your contact email and whether we can discuss the issue privately.

PGP/GPG
-------
If you want to encrypt your message, provide your public key or request the maintainer's public key. If you include a PGP-encrypted message, state the key fingerprint used.

Response and timeline
---------------------
- We will acknowledge receipt within a few business days.
- The maintainer will assess the report and coordinate fixes; timelines depend on severity and complexity.
- We aim for responsible disclosure: coordinating a fix before public disclosure where practical.

Disclosure policy
-----------------
We follow responsible disclosure practices. We ask reporters to give maintainers reasonable time to address critical issues before public disclosure.

After disclosure
---------------
Once a fix is available, the maintainer will publish a note in the advisory and update the repository with mitigation/patch instructions.

If you are a security researcher
--------------------------------
Thank you — please indicate whether you'd like public credit for reporting the issue; we will credit contributors per project policies.
